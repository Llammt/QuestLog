# QuestLog — трекер квестов и заданий

QuestLog — это Android-приложение для отслеживания выполнения задач (квестов) в антураже фэнтези-РПГ. Позволяет создавать задачи, отмечать их выполнение, удалять и просматривать список. Данные хранятся локально в базе данных Room.

## Технологии

- **Kotlin** — основной язык
- **Coroutines + Flow** — асинхронность и реактивность
- **StateFlow** — управление состоянием UI
- **Room** — локальное хранение данных
- **ViewModel** — управление данными с учётом жизненного цикла
- **RecyclerView + DiffUtil** — эффективное отображение списков
- **Navigation Component** — навигация между экранами
- **MVVM** — архитектурный паттерн

---

## Функциональность

- ✅ Просмотр списка задач
- ✅ Добавление новой задачи
- ✅ Отметка о выполнении
- ✅ Удаление задачи
- ✅ Локальное сохранение (Room)
